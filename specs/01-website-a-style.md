# 视觉设计系统与主题规范

## 1. 基调

**山河舆图**：素纸为底、墨青为字、铜金为线、青瓷为辅。整体像一册可以漫游的图版档案，而不是资讯门户。

## 2. 色彩

| 语义 | 浅色（素图） | 深色（夜航） |
| :--- | :--- | :--- |
| 页面底色 | `#f4f0e6` | `#0a1311` |
| 卡片表面 | `#fbf8f0` | `#101d19` |
| 主文字 | `#16231f` | `#ece7d8` |
| 次级文字 | `#35463f` | `#c6c3b4` |
| 铜金强调 | `#96652a` | `#d2ac66` |
| 青瓷辅助 | `#4d7568` | `#6fa192` |
| 朱砂（印章） | `#a6402e` | `#c25a42` |

舆图区块使用一套固定的「图版色」（`--atlas-*`），在明暗主题下保持一致，以保证地图的印刷质感。

所有颜色必须通过 CSS 变量引用，禁止在页面或组件中硬编码色值。

## 3. 字体

- 西文正文与数据：`Inter Variable`（本地托管）。
- 西文标题：`Outfit Variable`（本地托管）。
- 中文标题：系统宋体栈（Songti SC / Source Han Serif SC / SimSun），形成史册气质。
- 代码与坐标：`JetBrains Mono Variable`（本地托管）。

## 4. 版式

- 容器宽 `1180px`；正文阅读宽 `46rem`。
- 区块纵向留白使用 `clamp()`，桌面端保持大面积留白。
- 标题左对齐，栏目标题使用 01/02/03 编号，与「档案」体例一致。
- 卡片圆角不超过 `8px`，以直线、细边框、发丝线分割为主。

## 5. 动效

- 只做三类：首屏入场、滚动淡入、罗盘缓慢旋转。
- 所有动效必须响应 `prefers-reduced-motion`。
- 不使用自动轮播、闪烁、弹窗等抢夺注意力的效果。
