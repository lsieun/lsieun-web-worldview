# 帝系与群臣专题规范

适用于 `type: "reign-crowd"` 的视图（当前：`/history/western-han-ministers.html`）。新增朝代或人物时，先读本文，再改数据。

## 一、页面结构

纵向是时间，自上而下。自左向右四层：

1. **年份轴**：一根脊线，主刻度带年份标签，标签密度随缩放自动调整（默认约 20 年一格，保证标签间距不小于 60px）。
2. **帝系条**：每位皇帝一道色块，按真实在位年长绘制。
3. **临朝轨**：虚线窄轨，只放临朝称制或辅政废立者（吕后、霍光、王莽），与帝系并列但不是臣工。
4. **臣工泳道**：每位人物一根细线，按生卒区间绘制。

图顶写明 `起 前 202 · 刘邦称帝`，图底写明 `讫 公元 8 · 王莽代汉`，不依赖读者从刻度估算。

## 二、坐标与尺度

- 纵向比例可调，滑条范围 2–8 px/年，默认 3.6。
- 比例说明必须写全公式：`前 202 — 公元 8 · 跨度 209 年 × 3.6 px/年 = 752 px`。只写「px/年」或只写总高都算信息缺失。
- **没有公元 0 年**：公元前 1 年之后直接接公元 1 年，纵坐标压缩一格。年龄、年长、总跨度一律按 `elapsedYears` 计算，不得用 `end - start` 直接相减。
- 公元后的年份一律写「公元 X」，禁止出现裸数字，以免读者分不清公元前还是公元后。
- **短在位不放大**：刘贺 27 日按真实比例可能不足 1px，以最小高度 3px 的细标表示并注明「在位二十七日」，不为其拉长尺度。长度必须始终表示时间。

## 三、泳道与横向位置

- 横向只表示避让，不表示任何数值。同一时代重叠的人各占一道，先后错开的人共用一道。
- 打包在构建期完成（`world.js`），不在浏览器里现算，保证无 JavaScript 也有正确版面。
- 组内按生年排序，逐个放入第一条「上一位已卒」的泳道。
- 先按组（文臣／武将／宗室／和亲）分桶，再组内打包，避免三十根线糊成一片。
- 不允许「一人一列」：人会随时代增加，列会无限变宽。

## 四、生命线编码

一根线表达三段：

- **起家之前**：2px 细淡线，表示已在世、未入仕。
- **起家之后**：4px 实线，表示在官。
- 交界处空心圆：起家年份。悬停卡片写「起家 约前 124」；推算值必须带「约」。
- 起家年份无载者，整条画细虚线，卡片注明「起家年份无载」。
- 起家年份早于图起点者（如萧何前 209），整条为实线，卡片注明「早于本图起点」。
- 生年早于图起点者（萧何、张良、韩信），线段自起点画起，顶端加虚线开口标记；生卒标签仍写真实生年，不谎称生于前 202。

## 五、事件

- 事件圆点 3.4px，铜色实心。
- **只在鼠标距圆点 12px 以内触发**，离得远只显示人物卡片，不显示事件信息。
- 触发时圆点放大 1.75 倍，并扩散一圈波纹（620ms，缩放至 3.4 倍渐隐）；`prefers-reduced-motion` 下关闭动画。
- 卡片第二行固定为 `年份 · 人名 · 年龄`，例：`前 99 · 司马迁 · 46 岁`。年龄按年差计算。
- 事件标签默认隐藏，只有悬停该事件点、或固定该人物时才出现。固定人物显示其全部事件标签，属显式操作，不受距离限制。
- 事件年份必须落在视图范围内；早于起点的前史事件写进相关事件的说明文字，不设轴标。

## 六、帝系卡片

- 条内写**全名**：「汉高祖」「汉文帝」，不写单字「高」「文」。「西汉」前缀在页内省略。
- 极短在位按高度自动隐藏文字，只留色块，悬停仍可看全名。
- 卡片分三段，每段有小标题：
  1. `谥法 · 文`：写出谥法原文（「经天纬地曰文」）与这位皇帝一生最著之处，并说明「谥号是对一生的总结」。
  2. `在世（未必已仕）`：生卒区间覆盖该朝的人数与名单。
  3. `此时在官`：另按起家年份判定的人数与名单。两者不可混同，措辞不得只写「在位臣工」。
- 无谥号者（前少帝、后少帝、汉废帝、孺子婴）用 `称号` 段，说明「为史称，非谥号」及原因。
- 第二行写 `生卒 · 在位年数 · 汉兴第 N 年`，以刘邦前 202 年称帝为汉兴元年，按即位年换算。
- 标题同时给个人名：「汉文帝 刘恒」；若个人名已含在称号里（如「孺子婴」），不重复追加。

## 七、生僻字注音

- 帝系与人物姓名中的生僻字必须在卡片标题里注音，格式 `刘奭（shì）`、`金日磾（mì dī）`。
- 注音写在 figure 数据的 `pinyin` 字段，模板不硬编码。
- 目前已注：刘奭 shì、刘骜 ào、刘衎 kǎn、金日磾 mì dī。

## 八、数据文件

| 位置 | 内容 |
| --- | --- |
| `src/_data/views/*.json` | 视图配置：范围、分组、cast、事件清单、说明文字 |
| `src/_data/figures/*.json` | 人物事实：生卒、生卒是否约数、起家年份、拼音、简介 |
| `src/_data/events/*.json` | 事件：年份、关联人物、标题、说明 |
| `src/_data/dynasties/*.json` | 帝系：rulers（称号、在位、状态）、regencies（临朝与辅政） |

人物字段说明：

- `birthApprox` / `deathApprox`：生卒为约数，标签自动加「约」。
- `careerStart`：起家年份；`careerApprox` 为推算值时加「约」。
- `pinyin`：仅生僻字需要。

## 九、新增内容的步骤

新增一位臣工：

1. 建 `figures/<id>.json`，填 `name`、`birth`、`death`、`careerStart`、`summary`，生僻字加 `pinyin`。
2. 建所需 `events/<id>.json`，年份须在视图范围内。
3. 在视图 `cast` 中加一行并指定 `group` 与 `role`，在 `events` 中登记新事件。
4. 构建；若报错提示年份越界或生卒越界，按提示修正，不要绕过校验。

新增一位皇帝：改 `dynasties/*.json` 的 `rulers`，并在 `figures/` 补人物；谥法释义在 `world.js` 的 `POSTHUMOUS` 表里加一行，缺省会退化为「称号」段。

新增临朝或辅政：改 `dynasties/*.json` 的 `regencies`，`label` 取「临朝称制」「辅政与废立」等，`note` 写清对后续帝位的影响。

## 十一、决策记录

- **帝系高亮**：悬停某位皇帝时，只高亮该条；只有悬停人物时，才按其所历朝代点亮多条。齿轮式的连带高亮会让人误以为整段都是同一朝。
- **临朝人物的事件**：吕后、霍光、王莽的重要事件同样以铜点标在临朝轨上，悬停卡片与臣工一致（年份 · 人名 · 事件）。
- **视图范围**：前后各留一小段「前史」与「后续」（当前为前 210 — 公元 23），西汉帝系只占中间，前史/后续以灰底并标注「秦末」「新莽」；帝系条不为空白段伪造年号。
- **卡片复制**：点击图内元素固定卡片，卡片转为可选中文本，鼠标移开不消失；按 Esc 或点击空白处关闭；悬停预览仍保持移开即消失。
- **参考文章入口**：《谥法》属参考条目，不占一级导航，入口放在史册页标题下方的「参考」行。
- **版本库范围**：`docs/competition/` 为参赛材料，已写入 `.gitignore` 并从版本库移除。

## 十二、模板入口与复用边界

- **模板入口**：`src/_includes/reign-crowd-page.html`；页面先 `{% set crowdView = world.crowdViews["..."] %}`，再 include。数据与校验规则见[数据契约与构建校验](数据契约与构建校验.md)。
- **与帝系双视图的分工**：本模板回答“谁在谁的朝里活着、做事”，横向是避让、纵向是时间；帝系双视图回答“谁继位、从哪里来”，两种阅读任务不同，不合并成一个模板。
- **只适用于西汉的写死项**：`world.js` 中的「汉兴第 N 年」「秦末」「新莽」段标、`POSTHUMOUS` 谥法表与 `bandTitle` 的「西汉」前缀剥离，都是西汉专用。新增其他朝代的群臣页前，先把这些改为数据字段，否则卡片与图顶图底会写错。
- **纵向比例与事件距离**：比例滑条、事件点 12px 触发范围、固定卡片等交互参数写在 `reign-crowd.js` 与 `reign-crowd.css`，不要在各页面单独覆盖。
