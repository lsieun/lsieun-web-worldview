# 中外对比：页面布局

## 总体

逻辑视角（从左到右）

- 第1列，中国的TOC目录（时间正序）
- 第2列，中国的事件
- 第3列，时间轴（时间逆序）
- 第4列，国外的事件
- 第5列，国外的TOC目录

## 中国的 TOC 目录

- 要求
    - 时间：时间正序
    - 内容：夏、商、西周、春秋、战国、秦、秦楚之际、西汉、新、东汉、三国、西晋、东晋、南北朝、隋、唐、五代十国、宋辽金、元、明、清
    - 页面布局：不要出现“滚动条”

## 事件（适用于中国和国外）

- 要求
    - 字数：50个字以内，超出部分进行截断，因此尽量在50个字。如果存在例外，需要用有特定的“字段”标识。
- 不要写
    - 不要写模糊的事件，例如“脱贫攻坚取得全面胜利”，因为没有公开、客观可用的标准。
