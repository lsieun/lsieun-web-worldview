# 中外对比：页面布局

## 总体

- 页面三段式（从上往下）：
    1. **介绍区**：page-hero，已有。范围、每 50 年像素等信息
    2. **条件筛选区**：主题筛选（sticky 吸顶）
    3. **事件区**：5 列结构（TOC-左 | 中国事件 | 时间轴管道 | 世界事件 | TOC-右）

- 筛选状态持久化：localStorage key = `compare-filter-cat`

## 主题筛选

- 位置：介绍区下方，事件区上方，sticky top:0 吸顶
- 类别（按固定顺序）：
    - `all` — 全部（默认）
    - `general` — 通用（默认类别）：朝代建立/灭亡、战争、政治事件、制度改革、外交（非条约类）、宗教、探索
    - `treaty` — 条约：中国签订的不平等条约 + 对应世界侧的战争发动事件（鸦片战争、英法联军、甲午战争、八国联军）
    - `science` — 科技：造纸、印刷、蒸汽机、电磁、芯片、AI、医学、数学、大航海/地理发现
    - `art` — 艺术：文艺复兴、文学、绘画、建筑、音乐

- 数据层：每个事件 JSON 加 `"category": "xxx"` 字段，默认为 `"general"`
- 同年份同 side 合并事件时，categories 收集所有涉及的 category（数组），前端筛选用 `data-cats` 属性（空格分隔）匹配
- 筛选只影响事件条显示，**时间刻度和 TOC 导航不受影响**（sticky 筛选条始终可见）

| 1895 | 中日《马关条约》 |
| 1901 | 《辛丑条约》（11 国） |

| 年份 | 事件 | 国家 |
|------|------|------|
| 1840 | 英国发动鸦片战争 | 英国 |
| 1860 | 英法联军发动第二次鸦片战争 | 英国/法国 |
| 1894 | 甲午战争爆发 | 日本 |
| 1900 | 八国联军侵华战争 | 八国联军 |

## 中国的 TOC 目录

- 要求
    - 时间：时间正序
    - 内容：夏、商、西周、春秋、战国、秦、秦楚之际、西汉、新、东汉、三国、西晋、东晋、南北朝、隋、唐、五代十国、宋辽金、元、明、清
    - 页面布局：不要出现"滚动条"

## 事件（适用于中国和国外）

- 要求
    - 字数：50个字以内，超出部分进行截断，因此尽量在50个字。如果存在例外，需要用有特定的"字段"标识。
- 不要写
    - 不要写模糊的事件，例如"脱贫攻坚取得全面胜利"，因为没有公开、客观可用的标准。

## 中国事件

- 记录中国各个朝代的建立和灭亡（21 个朝代全覆盖）
