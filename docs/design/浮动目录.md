# 浮动目录 (TOC)

适用于 `entry.html` 详情页和 `default.html` 专题页。JS 在运行时扫描 `<main>` 内的 `<h2>` / `<h3>`，自动构建一个固定定位的浮动面板（`position: fixed`），不挤占正文布局空间。

## 一、启用条件

满足以下全部条件才会注入 TOC：

1. 页面通过 `entry.html` 或 `default.html` 布局渲染（两者均已在底部引入 `toc.js`）。
2. `<main>` 内至少有 **2 个** `<h2>` 或 `<h3>` 标题（排除 `.page-hero`、`.section-head`、`.eyebrow` 等元信息容器中的标题）。
3. 视口宽度 ≥ **1360px**。

任一条件不满足时，TOC 不渲染，页面布局完全不受影响。

## 二、布局位置

```
 ┌───────────────────────────────────────────────┐
 │  ┌─────────┐                                  │
 │  │ 浮动目录 │         页面正文内容区             │
 │  │ 140px   │      (居中，不受 TOC 影响)         │
 │  │ fixed   │                                   │
 │  │ 左侧    │                                   │
 │  └─────────┘                                  │
 └───────────────────────────────────────────────┘
```

- **固定定位**：`position: fixed; top: 105px; left: 24px; z-index: 50`，距浏览器左边缘 24px，不随正文滚动而离开视野。
- **独立面板**：带 `background-color`、`border`、`box-shadow`，像一个"悬浮卡片"浮在页面上方。
- **不挤占布局**：正文容器（`.container`）的宽度不受 TOC 存在与否的影响 — 不管 TOC 是否出现，正文始终是居中的正常宽度。
- 视口 < 1360px：CSS 强制 `display: none`，不占位、不遮挡。

## 三、交互细节

### 3.1 自动生成

- 遍历 `<main>` 内所有 `h2, h3`，过滤掉 `.page-hero`、`.reign-hero`、`.section-head`、`.eyebrow`、`.section-title` 容器内的标题（这些是页面元信息，不是正文分节）。
- 自动补全 `id`：取标题文字做轻量 slug（保留中文、字母、数字），重复时追加 `-N`。
- h3 必须紧跟在某个 h2 之后才会被归入其子列表；孤立的 h3 会被挂在最后一个 h2 下面。

### 3.2 整体收缩 / 展开

- TOC 顶部有 `‹ 目录` 按钮，点击可将整个面板收成一个竖排文字条（`writing-mode: vertical-rl`），只露出"目录"二字。
- 收缩状态持久化到 `localStorage.wv-toc-collapsed`（`0` = 展开，`1` = 收缩）。
- 用户首次访问默认为展开态。

### 3.3 单节折叠 / 展开

- 每个 h2 条目左侧有 `▸` 折叠按钮，点击可隐藏该 h2 下的 h3 子项。
- 折叠状态按 h2 粒度持久化：`localStorage.wv-toc-fold-<section-id>`。
- h3 条目自身没有独立折叠按钮，随所属 h2 统一折叠。

### 3.4 滚动联动高亮

- scroll 监听（`requestAnimationFrame` 节流，`passive: true`）实时追踪当前可见的最新标题。
- 距视口顶部 ≤ 120px 的 h2/h3 判定为"当前可见"，对应 TOC 条目加 `.is-active`（金色加粗）。
- 当前可见章节所在的 h2 组若已折叠，自动展开（并同步持久化状态），让用户看到自己在哪一节。
- 滚到页面底部时，高亮最后一个标题。

### 3.5 平滑跳转

- 点击 TOC 条目触发 `scrollTo({ top, behavior: 'smooth' })`，顶部留 90px 偏移（避开 sticky 页头）。
- 收缩态下点击竖排"目录"只能展开；展开态下点击标题才触发跳转。

### 3.6 回到顶部

- TOC 底部有 `↑ 回到顶部` 按钮，点击平滑滚到页面顶部（`window.scrollTo({ top: 0 })`）。
- 收缩态下底部队列一起隐藏。

## 四、标题层级约定（给作者的写作规范）

TOC 只识别 `<h2>` 和 `<h3>`，正文标题层级应严格遵循：

| 标签 | 语义 | 用途 |
| --- | --- | --- |
| `<h1>` | 页面标题 | 由布局模板页头自动输出，正文里**禁止**再用 h1 |
| `<h2>` | 一级章节 | 文章的主要分节。推荐写法：**"一、xxx"、"二、xxx"、"三、xxx"** 中文数字编号开头 |
| `<h3>` | 二级子节 | 某一 h2 下的细分。可选，用在一节内有明确并列主题时 |

**已定**：

- 详情页和专题页的 h2 必须用中文数字编号开头（`一、` `二、` …）。人物页、史册专题页、舆图页现已全部统一为编号风格。
- h3 不强制编号，直接写主题短语即可（如 `第一 / 第二阶梯界`）。
- 不要出现孤立的 h3（前面没有 h2），否则 TOC 会挂到上一个 h2 下，语义混乱。
- 同一页面内不要跳级（h1 → h3 没有 h2 隔开）。

## 五、哪些页面会有 TOC

| 布局 | 页面示例 | TOC 生效条件 |
| --- | --- | --- |
| `entry.html` | 人物详情页（项羽、刘邦…）、舆图详情页（胡焕庸线、秦岭淮河…）、史册专题页（楚汉、大航海…） | `.prose` 内 h2/h3 ≥ 2 |
| `default.html` | 历代皇帝专题页、谥法索引页 | `<main>` 内 h2/h3 ≥ 2（排除 hero/section-head） |
| 索引页 | `/figures/index.html`、`/history/index.html`、`/geo/index.html` | hero 内只有 1 个 h2，不触发（预期行为） |

## 六、不做什么

- 不支持 h4 及更深层级。世界观详情页的结构在 h3 层级已经足够表达，再深反而让正文臃肿。
- 不做全文搜索。搜索是索引页 / 站点级功能，不在 TOC 里重复。
- 不做多页面联动目录（如同一专题下多篇文章的跨页导航）。当前专题页是独立文档，如需跨页导航放在索引页处理。

## 七、技术要点

| 项目 | 值 |
| --- | --- |
| 入口文件 | `src/assets/js/toc.js` |
| 引入位置 | `entry.html` 和 `default.html` 底部（`defer` 脚本） |
| DOM 创建 | JS 在运行时向 `document.body` 直接 append `<nav class="toc-float">`，不依赖页面预设容器 |
| 扫描范围 | `<main>` 内全部 `h2, h3`，排除 `.page-hero, .reign-hero, .section-head, .eyebrow, .section-title` |
| 样式 | `components.css` 末尾 `.toc-float.*` 系列 |
| 依赖 | 无外部依赖，纯原生 JS |
| 滚动监听 | `requestAnimationFrame` 节流，`passive: true` |
| SSR 兼容 | 不涉及，纯客户端增强；禁 JS 时页面完全不受影响 |
| 暗色主题 | 全部 CSS 变量驱动，跟随 `[data-theme="dark"]` 切换 |
| 减少动画偏好 | 对 `prefers-reduced-motion` 禁用旋转过渡 |

## 八、已定决策与理由

1. **position: fixed 浮动面板，不挤占布局。** 初稿实现为 grid 三列（TOC | 正文 | 侧栏），但用户明确要求"浮动"。浮动面板意味着正文宽度永远不受 TOC 存在与否的影响 — 这是浮动面板 vs 布局列的核心区别。
2. **左侧而非右侧。** 右侧 210px 已用于档案信息（类目、年代、编号），且是用户视线的焦点区。左侧 TOC 是"辅助导航"，放在边缘不干扰主要内容。
3. **1360px 是启用阈值。** 正文已限宽 46rem（约 736px），加上档案侧栏 210px 和正常间隙，1360px 以下视口不够再放一个浮动面板而不遮挡重要内容。
4. **从 `.prose` 扩大到整个 `<main>`。** 初稿只在 `.prose` 内扫描，导致用 `default.html` 布局的专题页（如历代皇帝）没有 TOC。改成全 `<main>` 扫描并排除元信息容器后，所有正文 h2/h3 都能被覆盖。
5. **回到顶部而非回到底部。** 用户明确反馈，浮动面板上最常用的全局导航是"回到顶部"，底部是局部浏览区。
6. **JS 自建 DOM，不依赖页面容器。** 初稿在 `entry.html` 里留了 `<div class="toc-slot">`，限制了只能在 entry 布局生效。改成 JS 直接 append 到 body 后，两个布局都能用，且页面无需任何预置 HTML。
7. **首次访问默认展开。** TOC 是导航工具，默认展开让新读者"先看到全貌"，比让用户点一次展开更友好。
8. **中文数字编号 h2。** 与项目其他模块（时间轴组名、朝代段位）的编号风格一致，TOC 里一眼能看出文章有几节，顺序不会乱。
9. **不做 h4。** 详情页定位是"单主题 3–5 节，每节 2–4 段"的中长文，h4 意味着一节里还要再拆三层，说明该页主题选得过细，应该拆成多篇。
