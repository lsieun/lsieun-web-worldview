# 历史地图资源 · 调研报告

> 调研日期：2026-11-14 · 目标：为 lsieun-web-worldview 的历史专题页（特别是孔子游历列国）提供春秋时期诸侯国 GeoJSON 边界数据

## 核心结论

**没有现成的、可直接复用的"春秋列国 → GeoJSON"开源数据集。** 这个领域的数字化程度很低，主要障碍是版权壁垒和学术边界模糊。

---

## 资源清单（按实用价值排序）

### 1. Phersu Atlas ⭐⭐⭐⭐⭐ 最有学术价值，但 GeoJSON 不可直接下载

- **地址**：<https://content.phersu-atlas.com>
- **内容**：学术型历史 GIS 平台
  - 每个诸侯国（Polity）有独立页面，含**最大疆域多边形**
  - 覆盖时期：春秋早期（前 1000）→ 战国末期（前 221）
  - 具体诸侯国：鲁、卫、曹、宋、郑、陈、蔡、楚、齐、晋、秦、吴、越 等
  - 有"逐年领土变化"时间轴、最大疆域地图、人口密度图
  - Polity ID 示例：郑=3383, 周=7724, 晋=3396, 陈=1901
- **API/下载**：tile map 服务 + 文档说明（GeoJSON 格式），但具体下载端点未公开。`/data/max_polity/{id}` 返回说明文档 + 图片，不是原始数据
- **授权**：学术免费，商用需联系
- **对我们的价值**：可以作为边界参考底图，手动 trace polygon

### 2. historical-basemaps ⭐⭐⭐ 全球尺度

- **仓库**：<https://github.com/aourednik/historical-basemaps> （846★, MIT License）
- **GeoJSON 文件**：`world_bc1000.geojson` → `world_bc1500.geojson`（全球）
- **内容**：全球各国古代边界，但**中国只作为一个整体 polygon**，不是分朝代/分诸侯国
- **可用时间点**：前 1000 / 前 1500 / 前 2000 / 前 3000 / 前 123000 等
- **对我们的价值**：可作为底图参考（中原地区轮廓），但不能直接用

### 3. 复旦 CHGIS（中国历史地理信息平台）⭐⭐⭐⭐ 权威但未开放

- **地址**：<http://timespace-china.fudan.edu.cn>
- **内容**：基于谭其骧《中国历史地图集》的权威数字化
  - 含春秋战国等各时期时间切片
  - 2026 年启动重修，将新增数字地图形式向公众开放
- **现状**：平台可浏览查询，但原始 GeoJSON/Shp 未公开下载
- **对我们的价值**：学术权威参考，可比对边界

### 4. OSGeo 中国中心 ⭐⭐ 图片级

- **地址**：<https://www.osgeo.cn/map/m030b>
- **内容**：从网络获取原始图片 → 地图纠正 → WebGIS 发布
  - 有"春秋时期郑国/宋国/卫国"等专题图
  - 来源于《中国历史地图集》
- **格式**：**只有图片 + 坐标配准**，无 GeoJSON
- **对我们的价值**：视觉参考，无法直接程序使用

### 5. 谭其骧《中国历史地图集》⭐⭐⭐⭐⭐ 终极权威（纸质）

- **作者**：谭其骧（唯一文科院士）
- **出版**：中国地图出版社，1982
- **内容**：8 册，从原始社会到清末，涵盖所有朝代的疆域和疆域变化
- **现状**：版权保护，但 2026 年复旦启动重修，将新增数字地图版（预计 10 年完成）
- **对我们的价值**：如需要精确边界，这本书是最终标准

## 可落地的两条路

### 路线 A：参考 Phersu Atlas + 手动 trace polygon（推荐）

1. 打开 Phersu Atlas 各诸侯国的"最大疆域"地图（如 <https://content.phersu-atlas.com/metrics_summary/polity/3383.html>）
2. 截图作为底图放到 ECharts 上
3. 在 china-map.js 的 `buildOption` 里用 `geo.regions` 或叠加 `series.polygon` 手动定义各国边界（用简化拐点）
4. 每个主要诸侯国（鲁/卫/曹/宋/郑/陈/蔡/楚/齐/晋）约 1 小时，核心 10 国 = 1-2 天
5. 版权风险：边界来自学术来源，简化拐点后属于二次创作，风险低

### 路线 B：手动画简化中原底图 + 诸侯国 polygon

1. 以现代 china-provinces.geojson 为底，去掉省界
2. 只保留黄河/长江/泰山/太行/秦岭等地标（简化 line）
3. 用 circle 表示列国都城，polygon 表示大致势力范围（精度 ~30km 即可）
4. 优点：完全自主，零版权风险
5. 工时：1-2 天
